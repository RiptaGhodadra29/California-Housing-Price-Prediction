# California-Housing-Price-Prediction
A Machine Learning project that predicts California housing prices using Linear Regression, including Exploratory Data Analysis (EDA), data visualization, model evaluation, and model deployment-ready structure built with Python and Scikit-Learn.

## Project Overview

This project predicts house prices using Linear Regression and the California Housing Dataset.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Workflow

1. Data Loading
2. EDA
3. Data Preprocessing
4. Model Training
5. Evaluation
6. Model Saving

## Results

MAE : 0.5332

RMSE : 0.7456

R² : 0.5758
